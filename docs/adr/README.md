# Архитектурные решения (ADR)

Каждое решение — отдельный файл: контекст, решение, рассмотренные альтернативы, последствия.
Решение не переписывают задним числом: если оно меняется, пишут новое ADR, а старому ставят статус «Заменено ADR-NNNN».

Статусы:
- **Предложено**: решение принято как рабочее, но ждёт проверки (обычно spike, этап 10 плана).
- **Принято**: подтверждено и обязательно к исполнению.
- **Заменено**: устарело, см. ссылку.
